# 试卷：从材料/题目到学生版·教师版

> 老师 21:35："导入文档也可以用于生成试卷吧，要是输入题目也可以直接用吧"
> 设计：DSH；实现：codex（排在「导入 PPT 第一步」之后）

## 一句话

试卷入口有**两条用途**，别混为一谈（老师 11:00 纠正过一次）：

1. **当参考（主用途）**：导入一份已有的卷子 → 存成「题目参考」挂到课件上 → 生成新内容时，AI 参考它的**题型、难度、设问方式、考点覆盖**，但不照抄原题
2. **直接出卷**：题目/材料 → 排版成学生版·教师版（含答案），存进题库 `questions/` 复用

两条都从同一个入口进来、都吃 `.docx / .md / .txt / 粘贴`，出来的是两种东西。

## 现状

- `tools/questions.mjs`：题目 Markdown → 学生版 / 教师版 HTML（A4 打印友好），支持 `[单选][多选][判断][填空][解答]`、`- [x]` 标正确项、`> 答案：`/`> 解析：`
- 材料系统（`app/materials.mjs`）：课件可挂多份材料（粘贴/.md/.txt/.docx），生成时按 20k 字符预算进提示词
- 第一步已实现：宽松解析（5 型 + 未识别行号诊断）、学生版/教师版、题库落盘
- 第一步没做的：**试卷当参考**、**试卷入口吃 docx**

## 设计

### 入口

左侧新增「＋ 新建试卷」。打开对话框：

1. 选材料：下拉列出当前课件挂的材料（可多选），或直接在框里粘贴题目
2. 点「识别题目」→ 服务端宽松解析，回报「识别到 N 题：单选 5 · 填空 3 · 解答 2」或「没识别到题目」
3. 分叉：
   - **识别到题目** → 直接进入排版（不调 AI），可勾/取消某题
   - **没识别到** → 显示生成参数（题型分布、题量、总分、难度、是否要解析），确认后让 AI 按材料出题
4. 出「学生版」「教师版」两个 HTML，可打印/存 PDF；也有"另存为 .md 题库"供下次直接用

### 宽松解析（关键，不调 AI）

现有格式太严（`### 1. [单选]`），老师手上的材料五花八门。要认：

- 题号：`1.` `1、` `（1）` `第1题`
- 题型：`[单选]` 缺失时按"有 ABCD 选项"判单选/多选；无选项且有横线判填空；无选项且长文本判解答
- 选项：`A.` `A、` `A．` `（A）`，正确项可用 `√`/`*`/`【答案】A`/`答案：A` 任一种
- 答案/解析：`答案：` `答：` `【答案】` `【解析】` `解析：`，也接受文末单独一块"参考答案"
- 公式：`$...$` 原样保留（现有渲染器支持 KaTeX）
- **认不出来就列出来**：回报"第 12–15 行没看懂"，让老师改，不瞎猜

### 试卷结构（题单要升级）

在 Markdown 里支持：

```markdown
# 二次函数单元测（总分 60 分，60 分钟）

## 一、选择题（每题 3 分，共 15 分）

### 1. [单选] ……
```

- `##` 行 = 大题分组，带分值/题量
- **总分校验**（老师要求）：解析后自动算 `Σ(题数 × 每题分值)`，与卷头声明的总分比对；不等就**拦下不生成**，报出差在哪（"声明 60 分，实算 57 分，缺 3 分"）。没有分值信息时要求先填（每题分值或大题分值），不许静默放行
- 学生版：卷头（学校/班级/姓名/得分表格）+ 填空横线 + 解答留白（按分值给高度）
- 教师版：答案与解析集中或随题
- 兼容：没有 `##` 分组的旧题单仍按现状渲染（不许破坏 `examples/questions.md` 的输出）

### 题库（老师要求）

- 每次生成题单，顺手把这份 Markdown 存进 `questions/<日期>-<标题>.md`（含卷头：标题、总分、题数、时长），并提示"已存入题库"
- 目录里的 `.md` 就是题库本身——老师能直接改、能 diff、能拷给别人
- 「＋ 新建试卷」对话框里加一个「从题库选择」：列出现有题库（标题 · N 题 · 总分），支持整份套用或挑部分题
- 题库不进 dist 试用包（`.gitignore` + `tools/portable.mjs`），因为可能含学校内部题

### 生成参数（AI 分支）

题型分布（单选/多选/判断/填空/解答各几题）、每题分值、难度、是否给解析、总分自洽校验（题量×分值 = 总分，不匹配就报错让人改参数）。

## 现成项目：查了，不引入

- [AutoQ](https://github.com/rushikeshburle/AutoQ)、[examgenerator](https://zenodo.org/records/17337857)、[pexams](https://pypi.org/project/pexams/)：Python 生态，偏"题库抽题 + 批改"，不是"手写题目排版成卷"；**只借鉴组卷结构**
- [@speajus/markdown-to-pdf](https://cdn.jsdelivr.net/npm/@speajus/markdown-to-pdf@1.0.23/README.pdf)：输出 PDF，我们已有 A4 打印 HTML
- 结论：**沿用并扩展现有 `tools/questions.mjs`**，不引第三方

## 分步

1. **宽松解析 + 直接用 + 存题库**（不调 AI）：粘贴/材料 → 识别 → 出学生版/教师版 → 顺手存 `.md` 进 `questions/`
2. **试卷结构与总分校验**：`##` 大题分组、每题/每组分值、卷头、答题留白，总分不符就拦下（旧题单输出不变）
3. **题库复用**：从 `questions/` 选已有题库，整份套用或挑题
4. **AI 出题分支**：按参数与材料生成同格式题单

## 验收

- 粘贴一份常见格式的题目（A/B/C/D 选项 + 答案），能识别并排版；识别失败的题明确列出
- 生成后 `questions/` 下出现一份 `.md`，内容与刚生成的题单一致；下次能在「从题库选择」里看到
- 总分不符（声明 60、实算 57）时**不出卷**，报出缺口
- 旧 `examples/questions.md` 渲染结果逐字节不变（有基线就比基线）
- 学生版不含答案、教师版含答案与解析
- 材料里的题可以直接用，不经 AI；没挂材料也能单纯粘贴
