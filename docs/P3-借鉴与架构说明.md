## 二、模块职责与边界（遵守单向依赖、入口只接线）

1. **`src/widget-theme.mjs`**（纯渲染支撑，无上层依赖）
   - 输入：`packCss`、`themeCss`、`deckCss` 与原始组件 HTML。
   - 职责：解析课件生效主色/底色/前景色，自动计算对比度安全的表面色与边框色，向 `srcdoc` 注入 `<style id="ck-theme-vars">` 及 `Escape` 键转发脚本。
2. **`src/widget-templates.mjs`**（纯离线组件模板库，无网络/FS 依赖）
   - 导出：`WIDGET_TEMPLATES`（供前端展示模板预设卡片）、`detectWidgetTemplate(instruction)`、`buildWidgetFromTemplate(templateId, instruction)`。
   - 全部产出均通过 `src/widgets.mjs` 的 `checkWidget()` 离线安全校验。
3. **`src/template-store.mjs`**（服务端模板库存储层，依赖 `src/fs-retry.mjs`）
   - 导出：`listTemplates(rootDir)`、`renameTemplate(rootDir, id, newName)`、`deleteTemplate(rootDir, id)`、`buildTemplatePreviewDeck(rootDir, id)`。
4. **`app/tweak-inspector.mjs`**（前后端通用纯逻辑 + 编辑器微调属性栏构建器）
   - 导出：`mergeBlockTweak(list, incoming)`、`tweakHasEffect(tweak)`、`hiddenBlocksOf(page)`、`renderBlockInspector(...)`。
5. **`app/template-library.mjs`**（前端独立「模板库」弹窗控制器）
   - 导出：`initTemplateLibrary(ctx)`，通过显式回调与 `app/app.js` 通信，不读写未导出的隐式全局状态。
