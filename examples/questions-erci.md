# 二次函数 y = ax² · 课后练习

### 1. [单选] 抛物线 $y = 3x^2$ 的开口方向是（　）
- [x] 向上
- [ ] 向下
- [ ] 先向上后向下
- [ ] 无法确定
> 答案：向上
> 解析：$a = 3 > 0$，开口向上。开口方向只看 $a$ 的符号。

### 2. [单选] 抛物线 $y = -2x^2$ 的顶点坐标是（　）
- [ ] $(0,\;-2)$
- [x] $(0,\;0)$
- [ ] $(-2,\;0)$
- [ ] $(2,\;0)$
> 答案：$(0,0)$
> 解析：$y = ax^2$ 的顶点永远是原点，与 $a$ 无关。

### 3. [填空] 抛物线 $y = 5x^2$ 的对称轴是 ______。
> 答案：$y$ 轴（即 $x = 0$）
> 解析：$y = ax^2$ 的图像关于 $y$ 轴对称，对称轴是 $x = 0$。

### 4. [判断] 在 $y = ax^2$ 中，$|a|$ 越大，抛物线的开口越窄。
- [x] 正确
- [ ] 错误
> 答案：正确
> 解析：同样取 $x = 1$，$|y| = |a|$，$|a|$ 越大点越高，曲线越窄。

### 5. [填空] 当 $a < 0$ 时，$y = ax^2$ 有最 ______ 值，这个值是 ______。
> 答案：大；0
> 解析：$a<0$ 开口向下，顶点是最高点，所以有最大值 0。

### 6. [解答] 已知抛物线 $y = ax^2$ 经过点 $(2,\;-8)$，求 $a$ 的值，并说明开口方向。
> 答案：$a = -2$，开口向下
> 解析：把 $(2,-8)$ 代入得 $-8 = a\cdot 2^2 = 4a$，所以 $a = -2 < 0$，开口向下。

### 7. [解答] 比较 $y = 2x^2$ 与 $y = 0.5x^2$ 的开口宽窄，并说明理由。
> 答案：$y = 2x^2$ 的开口更窄
> 解析：$|2| > |0.5|$，$|a|$ 越大开口越窄；也可以取 $x=1$ 比较函数值 $2 > 0.5$。

### 8. [多选] 关于 $y = -x^2$，下列说法正确的是（　）
- [x] 开口向下
- [x] 顶点是 $(0,\;0)$
- [x] 当 $x > 0$ 时，$y$ 随 $x$ 增大而减小
- [ ] 有最小值 0
> 答案：前三项
> 解析：$a = -1 < 0$ 开口向下；顶点 $(0,0)$；$a<0$ 时右半支下降；有最大值 0，没有最小值。
